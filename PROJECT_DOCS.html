أسئلة قد تُسأل في المسابقة — مع الإجابات

❓ ما الفرق بين الـ Front-End والـ Back-End في مشروعك؟ ▼
الـ Front-End هو كل ما يراه الزائر: التصميم، الألوان، السلايدر، القوائم — وهو مبني بـ HTML وCSS وJavaScript.

الـ Back-End هو الجزء الخفي الذي يحفظ البيانات ويديرها — وهو مبني بـ Supabase الذي يوفر قاعدة بيانات وAPI جاهزة. عندما يرسل الزائر طلب تسجيل، الـ Back-End يحفظه ويجعله متاحاً للأدمن.
❓ لماذا اخترت Supabase بدل Node.js أو PHP؟ ▼
Supabase يوفر كل ما يوفره Node.js + Express + قاعدة بيانات في خدمة واحدة مجانية. بدل ما أبني API من الصفر وأدفع استضافة، Supabase يعطيني API جاهزة وقاعدة بيانات PostgreSQL وأمان مدمج — وكل هذا مجاناً. هذا يوفر وقتاً وجهداً ويسمح لي بالتركيز على جودة الموقع.
❓ كيف تحمي الموقع من الهكر؟ ▼
المشروع محمي بعدة طبقات:

1. RLS (Row Level Security) — قواعد في Supabase تمنع أي شخص من قراءة البيانات السرية مثل طلبات التسجيل حتى لو عنده المفتاح.

2. حماية XSS — كل نص يكتبه المستخدم يتم تنقيته قبل عرضه حتى لا يقدر أحد يحقن كود خبيث.

3. Rate Limiting — حد أقصى 10 تعليقات في الساعة و3 طلبات تسجيل في 24 ساعة لمنع السبام.

4. التعليقات تحتاج موافقة — لا يظهر أي تعليق بدون موافقة الأدمن أولاً.
❓ كم تكلف استضافة هذا الموقع؟ ▼
صفر دولار — مجاني 100%!

GitHub Pages مجاني لاستضافة الملفات الثابتة.
Supabase مجاني حتى 500MB قاعدة بيانات وحتى 2GB bandwidth شهرياً — وهذا يكفي لموقع مدرسة بسهولة.
❓ كيف يعمل نظام الأدمن؟ ▼
لوحة التحكم موجودة في admin.html — صفحة سرية لا يعرفها إلا الأدمن. عند الدخول بكلمة المرور، تظهر لوحة تحكم كاملة تتصل بـ Supabase مباشرة وتجيب كل البيانات. الأدمن يقدر يوافق على التعليقات، يغير حالة الطلبات، يضيف أخبار، ويشوف إحصائيات الزيارات — كل هذا في الوقت الفعلي.
❓ ما الفرق بين موقعك والموقع الأصلي للمدارس العمرية؟ ▼
الموقع الأصلي ثابت ومحدود. موقعي يضيف:

✅ تصميم عصري داكن وفاتح
✅ نظام تعليقات حقيقي متصل بقاعدة بيانات
✅ نظام تسجيل متكامل يحفظ البيانات
✅ لوحة تحكم للإدارة
✅ عداد زيارات حي
✅ إدارة أخبار ديناميكية
✅ حماية أمنية كاملة
✅ سرعة عالية لأن الاستضافة على GitHub Pages
❓ كيف تضيف خبر جديد للموقع؟ ▼
1. افتح admin.html وسجّل دخولك
2. اضغط على إدارة الأخبار من القائمة
3. اضغط + إضافة خبر جديد
4. اكتب العنوان والمحتوى واختر التصنيف
5. اضغط حفظ — الخبر يظهر في الموقع فوراً بدون ما تلمس أي كود!
❓ ماذا يحدث عندما يرسل زائر تعليقاً؟ ▼
1. الزائر يكتب تعليقه ويضغط إرسال
2. comments.js يرسل البيانات لـ Supabase
3. يُحفظ في جدول comments بحالة غير معتمد
4. الأدمن يشوفه في لوحة التحكم تحت "بانتظار الموافقة"
5. الأدمن يضغط موافقة → التعليق يظهر للجميع في الموقع ✅

هذا يمنع أي تعليق غير لائق من الظهور.
